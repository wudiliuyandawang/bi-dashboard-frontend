# bi-dashboard-frontend
基于 Vue3 + TypeScript + Vite 开发的商业智能可视化看板前端项目

## 📌 项目介绍
本项目是一套BI数据可视化仪表板，集成多种图表组件，展示业务统计数据，支持跨页面路由切换。
技术栈：Vue3 + TypeScript + Vite + Element Plus + ECharts + Pinia

## ✨ 功能特性
- 深色科技风格可视化仪表盘
- 多类型统计图表（折线图、柱状图、饼图等）
- 路由管理、组件化开发
- 封装统一请求工具，支持接口数据获取
- 适配浏览器路由，部署兼容 SPA 静态站点

## 🛠 环境依赖
- Node.js >= 18
- npm / pnpm

## 🚀 本地运行
```bash
# 安装依赖
npm install

# 启动开发服务
npm run dev

# 打包构建
